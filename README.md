### 🤖 Chupi — AI-Native Security Research Engine *(launching soon)*

Over the last 6 months, I've been building **Chupi** — an **AI-native security research engine for smart contracts, blockchains, and complex systems**.

Chupi is not a scanner and not a single prompt to an LLM. It's a full pipeline of coordinated agents that **read an entire codebase the way an auditor would**, then **hunt the way a researcher does**.

**Why it's different:**

- 🧠 **Reads like an auditor** — builds a complete understanding of the codebase: every function, every state transition, every trust boundary, cross-referenced into a knowledge graph with nothing assumed and every claim tied to exact source.
- 🔗 **Hunts like a researcher** — reasons across function boundaries to find the indirect bugs that are invisible per-function but break the system when pieces interact — the class of bugs that pattern-matchers and isolated function review simply cannot reach.
- 📐 **Evidence-driven, not vibes** — every observation carries file + line + hash. Claims are only as strong as their citations; nothing gets promoted on confidence alone.
- ✅ **Honest coverage** — accounts for every function and every analysis field. What wasn't reached is explicitly reported instead of silently skipped, so you know exactly what the audit missed.
- ⚡ **Resumable & live** — everything checkpoints to a durable store; a run interrupted after hours resumes in seconds. Results stream live to a web console.

The short version: **Chupi turns codebase auditing from a prompt into a pipeline — exhaustive reading, adversarial cross-function reasoning, and evidence-graded findings, at a scale a human team can't hold in their heads.**
